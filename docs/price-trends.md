# 价格趋势

入口：采购与销售 → 价格趋势（`/price-trends`）。页面和查询操作遵循当前项目菜单权限。

## 对应功能

- 货号来自订货记录，排除空货号，去重排序，默认选择第一项。
- 货号可搜索、清空；年份为当前上海年份及之前五年。更改货号或年份自动查询，也可点击“查询”重新读取。
- 读取对应货号当年全部订货单价，包含已完成/未完成、含税/未税记录，直接使用记录单价，不额外换税。
- 同日期同单价合并为一个点，同日期不同价保留多个点，按日期、单价升序排列。
- 图表使用时间轴，同一天的价格共享横坐标；单价轴按实际价格范围留白并按 50 元对齐。单位为元/吨，提示显示完整日期及两位小数单价。
- 超过 800 个去重价格点时启用 ECharts LTTB 降采样。图表随容器尺寸变化，支持减少动态效果；键盘左右键可逐点读取全部价格。
- 空数据、未选货号和查询失败均有独立提示；并发切换筛选时忽略过期响应。

## 数据来源

新增 `PurchaseOrder` / `purchase_orders` 数据结构，保留原项目订货主表字段。价格趋势只读取 `item_code`、`order_date`、`unit_price`，不混入首页价格表、客户订单或库存入库价格。

当前订货管理页仍为占位页，本次补齐价格趋势和它依赖的订货数据表。后续订货管理应复用此表。本次没有导入旧项目业务数据。
