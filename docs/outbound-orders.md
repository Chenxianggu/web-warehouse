# 发货出库

入口：`/outbound-orders`。对照参考项目的 `frontend/src/views/Outbound.vue`、`frontend/src/utils/deliveryNotePrint.js` 和 `backend/server.js` 中 ship/unship 接口实现。

## 页面操作

- 待出库与已出库列表各自保留日期、客户姓名/编号模糊搜索、每页 10/20/50/100 条、页码及跳转。默认日期取上海当天，清空日期后查询全部。
- 点击订单可查看详情、客户信息、明细与金额。
- 待出库订单的打印预览提供“仅出库”与“确认打印并出库”；已出库订单提供“确认打印”，重打不扣库存。
- 预览缩放范围 50%–250%，步长 10%，默认/重置为 110%；缩放不影响打印尺寸。
- 出货单复用参考的 241mm × 140mm 纸张版式、公司资料、签收说明；每张 5 行，空行补齐，末张显示合计及人民币大写。重量按每吨包数换算，单价按每公斤显示；寄仓订单第一行备注追加“提以往库存”。支持隐藏单价、金额及合计。
- Excel 导出以已出库列表选择的日期及客户关键词为条件，导出全部匹配明细。列与参考一致：客户姓名、塑料编号、包数、单价、小计。需要先选择日期。

## 库存与客户寄存

出库在事务中更新订单状态并按入库日期 FIFO 扣减库存。库存不足仍允许出库并返回警告：无入库记录时新增负库存行，否则不足部分扣到最后一条入库记录。取消出库新增无价格的正数回库记录，与参考系统一致。

寄仓勾选后，对客户姓名及塑料编号匹配、状态为 `finished` 的 `futures` 记录，以吨为单位扣减：优先选剩余量最接近且够扣的单笔；否则按订货日期 FIFO，仍不足扣到最新一笔。没有匹配寄存记录时不创建虚构寄存记录。历史保留日期、吨数与 `order_id`；取消出库精确撤销该订单的历史，避免每吨包数变更影响回滚。吨数保存 8 位小数以支持非 40 包/吨换算。

同单重复塑料合并扣减；订单条件写入和按塑料加事务锁，避免并发重复出库或库存重复扣减。所有服务端入口继续使用现有菜单权限。

## 验证

- `npm run test:outbound`：寄存分配、打印分页与隐藏金额、HTML 转义、重量、大写金额、筛选校验和 Excel 内容。
- PowerShell 设置 `$env:RUN_DATABASE_TESTS='1'` 后运行 `npm run test:outbound:db`：真实数据库的 FIFO、负库存、重复/并发出库、寄存扣减与回滚、失败回滚、筛选与分页。临时数据自动清理。
- `npm run db:generate`、`npm run db:migrate`、`npm run db:validate`、`npm run typecheck`、`npm run lint`、`npm run build`。
