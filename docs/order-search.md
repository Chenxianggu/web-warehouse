# 订单查询

入口：`/order-search`。对照参考项目 `frontend/src/views/OrderQuery.vue` 和 `GET /api/orders` 实现。

- 初次进入不限定日期或出库状态，默认每页 20 条。
- 订单号、客户编号/姓名支持模糊查询；日期范围包含开始和结束当天。查询按钮和输入框回车执行查询并回到第一页，重置清空条件并查询全部订单。
- 每页可选 10/20/50/100 条，支持页码、上下页和跳转；修改每页条数回到第一页，结果变化后超出范围的页码自动调整。
- 列表显示订单号、客户编号、客户姓名、收货单位、订单日期与状态，点击整行或订单号打开只读详情并高亮当前行。
- 详情重新读取当前订单，包含收货单位、状态、创建时间、塑料编号/名称、包数、单价、备注、小计及合计。金额公式沿用 `单价 ÷ 每吨包数 × 包数`，未建档塑料默认每吨 40 包。
- 列表与详情都独立检查订单查询菜单权限，不依赖其他模块的可见性。

复用当前订单表，无需新增数据库迁移。日期范围控件增加可选名称参数，既有入库页面默认名称保持不变。

验证：`npm run test:order-search`；设置 `$env:RUN_DATABASE_TESTS='1'` 后运行同一命令，可验证真实数据库的组合筛选、日期边界、两种出库状态及分页，临时数据会自动清理。
