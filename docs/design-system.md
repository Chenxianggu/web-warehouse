# 仁众塑料界面视觉规范

本规范用于仓储管理系统的全部页面。登录页是当前视觉基准，后续页面应延续同一种产品语言，而不是仅复制几个颜色。

## 视觉定位

界面提供黑金深色与「瓷白 · 香槟金」浅色两套主题，共用切角、细线、排版与信息层级。深色采用沉静的黑色空间、冷香槟金结构线、短暂的洋红故障信号，以及表示系统在线状态的冰蓝色；浅色采用雾白画布、白色实体面板、石墨文字与深金结构。整体应显得精密、克制、有识别度。

## 全局颜色令牌

颜色变量定义在 `src/app/globals.css`，组件必须引用变量，不要重复写十六进制颜色。

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--rz-black` | `#030303` | 页面主背景 |
| `--rz-panel` | `#0B0B0D` | 表单、侧栏和弹层表面 |
| `--rz-panel-raised` | `#111114` | 悬浮或选中表面 |
| `--rz-gold` | `#C9A96E` | 主操作、标题、边框和焦点 |
| `--rz-magenta` | `#FF2D78` | 故障分色、错误和极少量强调 |
| `--rz-cyan` | `#66F7FF` | 在线、连接成功和实时状态 |
| `--rz-ivory` | `#F2F2EC` | 主文字 |

深色颜色比例建议：黑色与深色表面占 80% 以上，香槟金不超过 15%，洋红与冰蓝合计不超过 5%。浅色以白色和中性灰为主，金色只承担主要操作及结构强调。

## 浅色主题与切换

登录页右上角与后台顶部使用无可见文字的圆角图标按钮。深色时显示太阳，点击切换到浅色；浅色时显示月亮，点击切换到深色。按钮提供说明下一步操作的无障碍标签，支持键盘操作与清晰焦点。首次访问默认深色，偏好以 `rz-theme` 保存在当前浏览器，刷新、登录跳转及同源标签页同步生效；已保存的跟随系统偏好仍可响应系统外观，点击按钮后改为明确的浅色或深色选择。存储不可用时仍可在当前页面切换。文档头部脚本在首次绘制前设置主题，防止闪屏。

| 角色 | 浅色色值 | 令牌 |
| --- | --- | --- |
| 页面画布 | `#F5F6F8` | `--background` / `--rz-bg` |
| 内容面板 | `#FFFFFF` | `--rz-panel` |
| 表头、悬停与次级表面 | `#EEF0F3` | `--rz-panel-raised` |
| 正文 | `#202328` | `--rz-ivory` |
| 辅助文字 | `#626873` | `--muted-foreground` |
| 普通分隔 | `#D9DDE3` | `--rz-edge` |
| 主操作填充 | `#C3A36C` | `--rz-gold-fill` |
| 主操作文字 | `#202328` | `--rz-on-gold` |
| 金色文字与焦点 | `#806329` | `--rz-gold` |
| 在线、成功 | `#087C88` | `--rz-cyan` |
| 错误、异常 | `#BC2458` | `--rz-magenta` |

- `--rz-black` 与 `--rz-ivory` 为兼容旧组件保留的主题角色别名，不能据名称假定为固定黑白色。新增主按钮必须分别使用 `--rz-gold-fill` 与 `--rz-on-gold`，输入表面使用 `--rz-input-bg`。
- 半透明结构使用统一的 `--rz-*-rgb` 通道变量。浅色文字设最低不透明度，金、青、洋红小字使用完整深色值；边框与装饰仍可低透明度。
- 表格采用浅灰表头、白色数据区、灰色悬停；金额和数量以深色为主。选中状态可以淡金强调，业务状态保留图标或文字，不只依赖颜色。
- 阴影和遮罩通过 `--rz-shadow-strength`、`--rz-overlay-strength` 适配主题，不将浅色弹窗置于厚重黑色遮罩之上。
- 浅色登录页保留构图和切角，降低背景装饰，停用持续扫描与自动故障分色；后台切页不显示扫描光。两套主题均尊重减少动态效果偏好。
- Canvas 图表需在主题变化时重新读取变量并更新坐标、网格、数据线和提示框。Portal 弹层必须从根元素继承主题。
- 用户点击主题按钮时使用 360ms 整页快照交叉淡入，背景、文字、渐变、弹层和 Canvas 图表同步过渡。旧画面保持不透明，新画面平滑覆盖，避免出现透底闪白。快照期间停用局部颜色过渡，确保结束时没有二次跳变；不支持快照 API 时退化为 360ms 颜色过渡。首次加载及偏好初始化不播放切换动画；减少动态效果时直接应用主题。连续点击取消前一次动画，仅提交最后一次请求。

## 排版

- 使用项目现有 Geist 字体。
- 页面标题应粗壮、紧凑，允许轻微负字距；正文保持正常字距和较高可读性。
- 等宽字体只用于编号、协议、坐标和系统状态，不用于普通正文。
- 中文文案应直接说明功能，避免营销式口号堆叠。

## 形状与层级

- 主要面板使用 8–22px 的切角或 HUD 缺口，避免大圆角。
- 边框保持 1px，使用香槟金或低透明度象牙白。
- 页面必须保留足够留白，不能把所有区域都做成发光卡片。
- 主按钮使用香槟金实体底与深色文字；次要按钮使用对应主题的实体底和金色边框。
- 输入框采用主题实体底和切角，聚焦时显示金色边框，深色可使用轻微辉光。

## 下拉选择

- 固定选项统一使用 `src/components/ui/select.tsx` 的 `Select` 和 `SelectOption`，可搜索或允许手动输入的字段使用 `SearchCombobox`。不要新增可见的原生 `select` 或 `datalist` 菜单。
- 菜单使用主题实体面板、金色顶边和选中标记；浮层通过 Portal 展开，避免被表格或对话框裁切。分页使用紧凑尺寸，普通表单保持原有字段高度。
- 保留空值“全部”、数值分页、业务禁用状态和键盘焦点；桌面及 390px 手机宽度均需检查深浅两套主题。

## 动效

- 弹窗与遮罩统一使用公共 `Dialog` / `AlertDialog`：打开 220ms 淡入并上移 10px，关闭 160ms 淡出并下移 6px；退出期间保留原内容，避免表单先清空、面板突然收缩。
- 日期、搜索与选择菜单采用 150ms 进入、110ms 退出的小幅位移；移动侧栏采用 240ms 进入、180ms 退出的侧向滑动。减少动态效果时立即切换，不延迟卸载。
- 每个页面只设置一个主要的自动动效叙事，例如启动、扫描或数据接入。
- 故障效果应短暂出现，不能持续抖动文字。
- 状态灯可以低频呼吸，交互控件可在悬停或聚焦时增强边缘亮度。
- 优先使用 CSS 动画，避免为了装饰引入大型客户端动画依赖。
- 所有持续动画必须支持 `prefers-reduced-motion: reduce`。

## 页面延续方式

- 登录页：品牌故障字、不规则身份验证终端、扫描线。
- 后台页：黑色主画布、金色当前导航、深色切角内容面板、冰蓝在线状态。
- 表格页：金色表头分隔或选中标记，洋红仅用于异常，避免每个单元格发光。
- 对话框：深色 HUD 面板，标题和确认操作使用香槟金。
- 图表：优先使用香槟金、冰蓝、象牙灰；洋红仅标示风险或异常。

## 禁止项

- 玻璃拟态和大面积背景模糊。
- 蓝紫渐变的通用 SaaS 卡片。
- 酸性黄色、糖果色或偏离瓷白与香槟金体系的独立页面配色。
- 仓库货架、传送带等工业插画作为装饰主题。
- 无功能含义的标签、编号、统计卡片和持续闪烁。
- 为追求赛博朋克效果而降低表单、表格和正文的可读性。

## 验收清单

新增或修改页面时至少确认：深浅两套主题在桌面与 390px 手机宽度无横向溢出；键盘焦点清楚；文字对比度足够；减少动态效果生效；主题刷新持久化、跟随系统和弹层颜色正确；页面与登录页放在一起时属于同一个产品。
