# 仁众塑料界面视觉规范

本规范用于仓储管理系统的全部页面。登录页是当前视觉基准，后续页面应延续同一种产品语言，而不是仅复制几个颜色。

## 视觉定位

界面采用黑色赛博朋克终端风格：沉静的黑色空间、冷香槟金结构线、短暂的洋红故障信号，以及表示系统在线状态的冰蓝色。整体应显得精密、克制、有识别度。

## 全局颜色令牌

颜色变量定义在 `src/app/globals.css`，组件必须引用变量，不要重复写十六进制颜色。

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--rz-black` | `#030303` | 页面主背景 |
| `--rz-panel` | `#0B0B0D` | 表单、侧栏和弹层表面 |
| `--rz-panel-raised` | `#111114` | 悬浮或选中表面 |
| `--rz-gold` | `#C9A96E` | 主操作、标题、边框和焦点 |
| `--rz-magenta` | `#FF2D78` | 故障分色、错误和极少量强调 |
| `--rz-cyan` | `#66F7FF` | 在线、连接成功和实时状态 |
| `--rz-ivory` | `#F2F2EC` | 主文字 |

颜色比例建议：黑色与深色表面占 80% 以上，香槟金不超过 15%，洋红与冰蓝合计不超过 5%。

## 排版

- 使用项目现有 Geist 字体。
- 页面标题应粗壮、紧凑，允许轻微负字距；正文保持正常字距和较高可读性。
- 等宽字体只用于编号、协议、坐标和系统状态，不用于普通正文。
- 中文文案应直接说明功能，避免营销式口号堆叠。

## 形状与层级

- 主要面板使用 8–22px 的切角或 HUD 缺口，避免大圆角。
- 边框保持 1px，使用香槟金或低透明度象牙白。
- 页面必须保留足够黑色留白，不能把所有区域都做成发光卡片。
- 主按钮使用香槟金实体底与黑色文字；次要按钮使用深色底和金色边框。
- 输入框采用深色实体底和切角，聚焦时显示金色边框与轻微辉光。

## 动效

- 每个页面只设置一个主要的自动动效叙事，例如启动、扫描或数据接入。
- 故障效果应短暂出现，不能持续抖动文字。
- 状态灯可以低频呼吸，交互控件可在悬停或聚焦时增强边缘亮度。
- 优先使用 CSS 动画，避免为了装饰引入大型客户端动画依赖。
- 所有持续动画必须支持 `prefers-reduced-motion: reduce`。

## 页面延续方式

- 登录页：品牌故障字、不规则身份验证终端、扫描线。
- 后台页：黑色主画布、金色当前导航、深色切角内容面板、冰蓝在线状态。
- 表格页：金色表头分隔或选中标记，洋红仅用于异常，避免每个单元格发光。
- 对话框：深色 HUD 面板，标题和确认操作使用香槟金。
- 图表：优先使用香槟金、冰蓝、象牙灰；洋红仅标示风险或异常。

## 禁止项

- 玻璃拟态和大面积背景模糊。
- 蓝紫渐变的通用 SaaS 卡片。
- 酸性黄色、糖果色或浅色主题作为主视觉。
- 仓库货架、传送带等工业插画作为装饰主题。
- 无功能含义的标签、编号、统计卡片和持续闪烁。
- 为追求赛博朋克效果而降低表单、表格和正文的可读性。

## 验收清单

新增或修改页面时至少确认：桌面与 390px 手机宽度无横向溢出；键盘焦点清楚；文字对比度足够；减少动态效果生效；页面与登录页放在一起时属于同一个产品。
