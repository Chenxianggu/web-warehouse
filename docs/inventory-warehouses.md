# 本仓库与宏海仓

每种塑料分别维护本仓库和宏海仓的库存，两仓不自动互相补扣。

- 库存管理的「本仓库（包）」和「约（吨）」延续原库存；「宏海仓」列显示宏海仓包数及换算吨数。「×均价」仍为本仓库的入库成本。
- 入库登记选择入库仓库，保存后只增加该仓库库存。入库记录展示仓库，删除流水也只影响对应仓库。
- 客户订单可选择整笔订单的出库仓库；发货出库的打印预览中可在确认出库前调整。确认时仓库与已出库状态在同一事务保存，重复出库不会重复扣减。
- 出库沿用原来的先进先出及缺货记负库存逻辑，仅在选中仓库内扣减；不足时提示该仓库名称。取消出库回补实际出库仓库。
- 订货管理选择入库仓库，整单到货、手动标记已交货、分批到货及到期自动入库都沿用该仓库。已有入库记录时不能更改仓库；尚未入库时可修改。修改仓库后需先保存，再登记分批到货。
- 订货和已出库订单的 Excel 导出包含仓库。历史数据与未指定仓库的旧请求默认本仓库。

数据库迁移：`20261022000000_add_honghai_warehouse`。部署时按现有流程执行 `npm run db:generate`、`npm run db:migrate` 并重建应用；迁移会为原有入库流水、客户订单及订货单补上本仓库归属，宏海仓从零开始。

验证命令：`npm run test:warehouses`。数据库联动验证需在开发数据库上设置 `RUN_DATABASE_TESTS=1` 后执行 `npm run test:warehouses:db`，覆盖双仓隔离、缺货、出库仓库切换、取消出库、整单/分批/定时到货与重复同步。
